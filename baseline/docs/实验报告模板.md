## 2. 系统设计理解

### 2.1 PipeANN-Filter

结合论文，使用一至两个段落说明：

- 向量、图索引和过滤相关数据在 DRAM 与 SSD 中如何组织；

- 系统如何选择不同的过滤或路由方式；
- 该设计预期减少哪些开销，又可能引入哪些代价。

## 4. 实验结果与机制分析

本节同时回答“观察到了什么”和“为什么会出现该现象”。所有结论应引用具体测量数据，并区分直接测得的事实与根据论文或源码机制作出的推断。

本节必须完成两张核心图：

1. **Recall@10–Mean Latency 曲线**：使用 High workload，分别连接两套系统的三档 L；
2. **Selectivity–Performance 组合图**：横轴为 Low、Medium、High，使用三个子图分别展示 Recall@10、Mean Latency 和 Mean I/O。

图中使用三轮实验结果的中位数，并用误差线或范围表示波动。所有坐标轴应标明指标名称和单位，不同系统应使用一致且清晰的图例。表格用于提供具体数值，图表用于展示变化趋势。

索引大小、峰值 RSS 和系统内部行为指标可以使用表格展示；只有在能够帮助解释关键现象时，才需要增加额外图表。
